# Surface: Talasuri demo deck (docs/slides/index.html)

Mode: Persuade. Audience: competition judges. Job: in seven slides, understand the problem, see the app work on a real target, believe the measured results, and know how to try it. Constraint: the app's own world (DESIGN.md), real screenshots only, only README/description.md numbers; repo-only, self-contained HTML driven by keyboard.

## Direction contract

THESIS: The deck is a sequence of atlas plates: each slide is one plate, its subject named in the italic serif with a mono catalogue line beneath, and the evidence (a real capture) owns most of the frame. It refuses the pitch-deck default of centred headline, three icon cards and a gradient.

OWN-WORLD: The app's world unchanged: chart navy ink ramp, chalk text, 1px hairlines, the plate frame double neat-line around every capture, red only for the target ring and the one key action/number per slide, amber only for stated limits. Public Sans, Source Serif 4 italic for object and product names, JetBrains Mono tabular figures.

STORY: Judges see the product's title screen, the problem in four plain facts, then a target found, watched moving, measured and hunted, each with real captures and real numbers, and close on how to run it and whose data it is.

FIRST VIEWPORT: Slide 1 is the app's title screen as a slide: dimmed SPHEREx all-sky map, the logo, the tagline; its plate number lives only in the deck counter. Slides 2-7: 16:9 stage, plate number and section as the first item of the catalogue line beneath the heading, the capture in a plate frame, keyboard arrows and a 2px progress line along the bottom edge like the app header.

FORM: seed: none (pinned) "use the same style as that of the gui"; slide 1 pinned by the confirmed outline: "1 Title (logo over SPHEREx all-sky map, tala/suri)".

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
