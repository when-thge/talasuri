# Surface: Talasuri app (frontend/index.html, all tabs)

Mode: Operate. Audience: public/learners and citizen scientists (PRODUCT.md). Job: pick a target, watch it move or change, measure it. Constraint: keep logo/symbol files and the title screen; images stay untinted. Chosen 2026-11-15 by the user from two directions on the Superdesign canvas (draft 1562e923, "B · Star atlas").

## Direction contract

THESIS: The interface is a star-atlas plate: the sky image owns the screen and everything else is quiet chart furniture. It refuses the category default of a glowing neon HUD console with boxed panels on every side.

OWN-WORLD: Chart navy ground #0D1626, panel #111D31, hairline rules #22314A, chalk text #E9EEF5/#A9B6C9/#8A98AE; night-vision red #FF5A4E only for primary actions, the current selection and the target ring; amber #F2B544 for flags. Public Sans UI in sentence case, Source Serif 4 italic for object names, JetBrains Mono tabular figures for coordinates and measurements. Raises: action-only accent (from the warm consumer canon); nothing labelled twice (from the catalog-sleeve world); one fixed tonal ramp (from the zone-sheet world); 1px hairline discipline (from centre-rail setting).

STORY: A newcomer sees a named object, its picture, and a red play button; pressing it shows motion. A citizen scientist finds every setting behind a labelled rail and every measurement in one panel, one action away.

FIRST VIEWPORT: 56px header (wordmark, Basic/Advanced/Movers text tabs, centred search, release select, Share and Help icon buttons, 2px progress line). Advanced: 64px labelled icon rail, a 272px always-open settings column (rail + column = 336px, mirroring Measurements), the viewport (atlas-plate label: 2.5rem italic serif name over a catalogue line, view switch at right, hairline beneath; black stage inside a chart neat-line with RA/Dec ticks, red target ring with an acquire moment, scale line in the frame margin; tick strip, scrubber, player with red play, one caption line), 336px Measurements panel. No footer.

FORM: Star atlas chart plates, candidate 1 of my ordered list (Impeccable's pick; roll assigned candidate 5, Ephemeris, which the user declined). seed:5e7cb112ebf3bbd9. Signature move: the atlas-plate target label plus the red target ring, shared by the flipbook and sky maps.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
